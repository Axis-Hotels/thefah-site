# The FAH by Axis.Bangkok — сайт отеля

Сайт отеля The FAH (Silom Soi 6, Бангкок) на английском, русском и тайском. Каждая языковая версия — отдельная страница Тильды на axis-hotels.com с одним блоком T123 «HTML-код». Фото, логотип и карта раздаются через GitHub Pages из папки `docs/`.

**Идея:** Fah по-тайски — «небо». Первый экран показывает небо над Силомом в реальном времени Бангкока (рассвет, день, закат, ночь с огнями в окнах). Гость может перетащить солнце ползунком и посмотреть, как меняется небо.

## Блоки страницы

1. **Первый экран:** живое небо Бангкока, полный логотип с «by Axis.Bangkok», одно фото (гостиная Penthouse Suite) с ползунком неба, строка бронирования (заезд, выезд, гости).
2. **Номера** сразу после первого экрана: короткий текст и три фото, затем выбор номера: «Кто едет?», вкладки по 6 категориям, площади в масштабе, галерея с увеличением фото.
3. **Силом пешком и на метро** одним блоком: минуты до Патпонга, BTS, MRT и Люмпини; общая карта; переключатель «Пешком» (10 мест с фильтрами) / «На BTS и MRT» (9 направлений со схемой маршрута).
4. **Удобства и условия:** заезд, выезд, дети, парковка, бесконтактное заселение; 4 фото: лаундж, фасад, вход, лобби.
5. **Индивидуальный запрос** и **контакты** на ночном небе.

## Что где лежит

| Путь | Что это |
|---|---|
| `content/config.json` | Ссылка Exely, телефон, почта, WhatsApp/LINE, адрес GitHub Pages, адреса страниц в Тильде |
| `content/texts.json` | Тексты интерфейса EN / RU / TH, подписи к фото, вопросы и ответы |
| `content/rooms.json` | Номера: площадь, кровать, кому подходит, фото, описания на трёх языках |
| `content/places.json` | Места для карты с координатами; минуты пешком считаются автоматически |
| `content/routes.json` | Маршруты на BTS/MRT: линии, станции, число остановок, минуты |
| `content/map.json` | Привязка карты к координатам и формула «минуты пешком» |
| `scripts/fah.css`, `scripts/fah.js` | Дизайн и интерактив. Все стили начинаются с `.fah` и не конфликтуют с Тильдой |
| `scripts/build.py` | Сборка страниц (только стандартный Python) |
| `scripts/map_base.py` | Перерисовка карты района из выгрузки OpenStreetMap. Нужна только если меняется район |
| `tilda/thefah-{en,ru,th}.html` | **Готовый код для вставки в Тильду.** Генерируется, руками не править |
| `tilda/НАСТРОЙКИ СТРАНИЦ.md` | Title, description, адреса страниц и код для HEAD |
| `docs/` | Публикуется GitHub Pages: фото, логотип, карта, превью `docs/en/`, `docs/ru/`, `docs/th/` |

## Как внести правку

1. Поменять тексты в `content/*.json` или настройки в `content/config.json`.
2. Собрать: `python3 scripts/build.py`. Сборка остановится, если не хватает фото, подписи к фото или карты, и напомнит, какие настройки ещё пустые.
3. Превью: `python3 -m http.server 18621 --directory docs` → http://localhost:18621/en/.
4. Ветка → коммит → push → pull request.
5. Если поменялся текст или дизайн, заново вставить код из `tilda/thefah-*.html` в блок T123 и опубликовать страницу. Если поменялись только фото или карта, Тильду трогать не нужно.

## Публикация

Коротко: страницы живут на Тильде (`axis-hotels.com/thefah`, `/thefah-ru`, `/thefah-th`) — блок T123 с кодом из `tilda/` и скрытый блок формы Тильды для заявок; фото и карта раздаются GitHub Pages из `docs/`; бронирование — общий модуль Exely на axis-hotels.com.

**Форма запроса.** Код сам находит на странице блок формы Тильды, прячет его, добавляет в него все поля с понятными названиями (Тип запроса, Имя, Контакт, Заезд, Выезд, Гости, Номера, Комментарий, Язык страницы, Страница) и отправляет. Письмо уходит получателям этой формы в Тильде (love@axis-hotels.com). Если блока формы нет, откроется почтовая программа гостя с письмом на `email` из `config.json` (ненадёжно).

## Бронирование (Exely)

На axis-hotels.com работает **один общий модуль Exely** для всех отелей Axis в Бангкоке (интеграция `BE-INT-axis-hotels-com`): Axis.Bangkok (506590), Axis.Bangkok Chess (515128) и the Fah (**515836**). Отдельной ссылки «на модуль the Fah» нет: бронирование идёт на общей странице, а нужный отель выбирается параметром.

- Страницы бронирования уже есть на Тильде: `axis-hotels.com/ru/bangkok/booking`, `/en/bangkok/booking`, `/th/bangkok/booking`. Скрипт Exely стоит на сайте.
- Кнопки «Забронировать» ведут на `…/{язык}/bangkok/booking?hotel_id=515836`. Строка бронирования добавляет `date`, `nights`, `adults` (проверено 20.11.2026). Кнопка у номера добавляет `room-type` из `content/rooms.json` → `exely_room`.
- Модуль открывается в той же вкладке (так требует чек-лист Exely).
- Архив от Exely (коды, номера тарифов, инструкция) — в письме от Exely; номера тарифов (`special-offer`) пока не используются.

**До запуска:**
1. В Exely открыть продажи the Fah: на 20.11.2026 вкладка «The FAH by Axis.Bangkok» на странице бронирования пустая («Здесь пока ничего нет»).
2. На страницах бронирования в Тильде обновить тексты: заголовок «…AXIS.Bangkok и AXIS.Bangkok Chess» и «Два отеля — два настроения Бангкока» теперь не включают the Fah.
3. После запуска сообщить менеджеру Exely, чтобы их команда проверила интеграцию.

## SEO

**Уже в коде:**
- разметка schema.org «Отель» на каждой странице: адрес, координаты, телефон, почта, заезд и выезд, удобства, бренд Axis Hotels и все 6 номеров (площадь, вместимость, кровати, удобства);
- после того как будет вписан `asset_base`, в разметку автоматически добавятся фото и логотип. После `booking_url` добавится действие «Забронировать»;
- ссылки на профили отеля (Google Карты, Booking, Instagram) добавляются в `config.json` → `same_as` и попадают в разметку;
- title и description с ключевыми словами (Silom, BTS Sala Daeng, MRT Si Lom, Патпонг) — в `tilda/НАСТРОЙКИ СТРАНИЦ.md`;
- связка языков (hreflang) — код для HEAD там же;
- один H1, разделы H2, номера H3, у всех фото есть подписи.

**Сделать вне кода (после публикации):**
1. Google Business Profile: переименовать в «the Fah by Axis.Bangkok», указать сайт `axis-hotels.com/thefah`, проверить адрес и телефон.
2. Если домен thefah.com ещё у отеля: перенаправление 301 с hotel.thefah.com на axis-hotels.com/thefah.
3. Одинаковые название, адрес и телефон на Booking, Agoda, Trip.com и в Google.
4. Подключить Google Search Console и Яндекс Вебмастер (настройки сайта в Тильде), отправить карту сайта.
5. Проверить разметку: https://search.google.com/test/rich-results — вставить адрес страницы.
