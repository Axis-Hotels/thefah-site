# Настройки страниц в Тильде

Файл собирается автоматически (`python3 scripts/build.py`). Копируйте значения отсюда в «Настройки страницы».

- **Адрес страницы:** `en/the-fah`

- **Описание (description):** Boutique hotel in Silom, a short walk from BTS Sala Daeng, MRT Si Lom and Patpong. Rooms for two, a penthouse with balcony and family rooms. Book direct.

## HTML-код внутрь HEAD (одинаковый для всех трёх страниц)

Настройки страницы → Дополнительно → «HTML-код для вставки внутрь HEAD»:

```html
<link rel="alternate" hreflang="en" href="https://axis-hotels.com/en/the-fah">
<link rel="alternate" hreflang="ru" href="https://axis-hotels.com/ru/the-fah">
<link rel="alternate" hreflang="th" href="https://axis-hotels.com/th/the-fah">
<link rel="alternate" hreflang="x-default" href="https://axis-hotels.com/en/the-fah">
```
